# Expense-Tracker
 Expense Tracker

A simple Python-based Expense Tracker that helps users manage their daily income and expenses, track their spending, set monthly budgets, and view financial reports.

This project was created to practice Python programming and understand how basic financial tracking works using a command-line application.

 Features

- Add income and expenses
- View transaction history
- Calculate total income, expenses, and balance
- Edit existing transactions
- Delete transactions
- Search transactions by date, category, description, or type
- Set monthly budgets for different categories
- Track budget spending and remaining amounts
- Generate daily, weekly, and monthly financial reports
- View expenses by category
- Display a simple text-based expense graph
- Automatically save data for future use

 Technologies Used

- Python
- JSON (for storing data)
- Built-in Python modules:
  - "datetime"
  - "json"
  - "os"

 Project Structure

Expense-Tracker/
│
├── main.py
└── expense_data.json

- main.py – Contains the complete Expense Tracker program.
- expense_data.json – Stores transaction and budget data automatically when the program runs.

 How to Run

1. Clone the repository

git clone https://github.com/shreyashi0007/Expense-Tracker.git

2. Navigate to the project folder

cd Expense-Tracker

3. Run the program

python main.py

How It Works

The program provides a menu through which users can select different operations.

Users can add income or expenses, view their transaction history, calculate their balance, manage transactions, set budgets, and generate reports.

The data is stored locally in a JSON file, allowing transactions and budgets to remain saved even after the program is closed.

 Purpose of the Project

The main purpose of this project is to make basic expense management easier while applying Python programming concepts such as:

- Functions
- Loops and conditional statements
- Lists and dictionaries
- User input handling
- File handling
- JSON data storage
- Date and time operations
